# UCNS gonol spiral identity

**Authority:** Erin Spencer  
**Recorded:** 2026-08-17  
**Status:** authority-declared semantic clarification  
**Selection effect:** none on unresolved coordinate, embedding, composition, or completion laws

## Clarification

**Each gonol is already a spiral.**

A gonol is not a non-geometric token or carrier record that later becomes a spiral when a renderer, coordinate law, or consumer acts on it. Spiral form belongs to gonol identity.

Therefore:

```text
gonol
!= thing transformed into a spiral

gonol
= spiral-bearing UCNS object
```

A downstream consumer may expose, serialize, project, animate, compare, or render that spiral. It does not create the spiral by doing so.

## Coordinate and implementation distinction

This clarification does **not** assert that every current UCNS implementation already exposes a complete coordinate realization of every gonol spiral.

The following remain distinct:

```text
gonol has spiral identity
!= complete machine-facing spiral coordinates are exposed
!= one display projection is the gonol
!= one candidate coordinate law is selected canon
!= higher-gonol composition is complete
```

Accordingly, historical/current statements that a bounded experiment has "geometry absent" or that a source-to-coordinate law is unresolved must be read narrowly when the subject is coordinate assignment, embedding, or a particular executable representation. They do **not** mean that a gonol lacks its intrinsic spiral nature.

## Display firewall

A figure-eight centerline, circle, Möbius projection, raster image, SVG, numerical path, or other view may represent part of a gonol spiral under a declared projection. The view is not automatically the complete gonol.

Likewise, failure to expose the full spiral through a current API is an implementation/exposure gap, not authority to replace the gonol with newly invented downstream geometry.

## txtsprl relation

`The-Interdependency/txtsprl` consumes existing gonol spirals.

```text
existing UCNS gonol spiral

```

There is no UCNS-gonol-to-spiral transformation step.

## Usage guidance

When code or documentation says a gonol's geometry is "missing," qualify the missing thing precisely:

- coordinate assignment;
- embedding;
- projection;
- machine exposure;
- composition law;
- or another named representation boundary.

Do not use "geometry absent" to imply that the gonol is not already a spiral.
