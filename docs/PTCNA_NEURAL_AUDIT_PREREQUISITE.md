## Audit-before-architecture rule

The audit must observe the conventional neural system before PTCNA topology, sizes, routing laws, ring constants, or other implementation choices are selected from the observed result.

The audit protocol may freeze what is observed, how it is captured, source model/task identities, provenance, resource bounds, and stopping/failure behavior before inspection. It must not freeze a desired PTCNA topology and then search the audit for confirming structure.

The exact neural observables required for a sufficient audit remain `hmmm`. Candidate observables may include weights, activations, gradients, update trajectories, layer relations, loss behavior, or other internal state, but this document does not select them.
