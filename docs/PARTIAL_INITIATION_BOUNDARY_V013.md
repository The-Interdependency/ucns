## Question

v0.12 showed that the affine non-null coordinate can be smooth while the
causal door into that coordinate space remains absent.

v0.13 asks the smallest executable version of that missing question:

> Can the existing typed Structural Null and source-bound v0.6 word
> initiations be attached to the exact v0.11 root coordinate through a
> provenance-bearing marked seam, with the twist and subsequent 360°/720°
> motion retained as evidence?

The answer is yes on the fixed partial domain. The result is not a full-carrier
continuity theorem.

### Collision check

The two claims are bounded and nonconflicting. A marked seam is one candidate
representation of the already-ratified EDCM seam sense. A partial attachment is
not another name for complete carrier continuity.

Downstream implementation is permitted only with the provisional scope and
nonselection firewall above.

## Explicit topology

v0.13 chooses one of the constructions allowed by v0.12 for experiment:

```text
Structural Null
  topology = disjoint typed marked prestate

non-null root
  coordinate = u=0, B=1, lifted turns=0

attachment
  relation = source-bound partial initiation edge
```

Structural Null is not treated as a numeric point, limit, binary64 coordinate,
empty value, or directed-cover null. It is connected to the exact non-null
root only by the declared partial relation. This is an explicit construction,
not a claim that the attachment is continuous as an arbitrary-real boundary
limit.

## Provenance-bearing seam

Each existing v0.6 `MobiusInitiationEvent` receives one
`MarkedInitiationSeam`. Its identity retains:

1. initiation event;
2. source witness;
3. word occurrence and source start;
4. exact turn-boundary or SPACE manifestation;
5. the singular typed Structural Null origin;
6. seam policy and version; and
7. `selection_effect = none`.

A `SeamCoordinateView` may place a numeric display cut anywhere modulo one
visible turn. Moving that cut leaves the marked seam identity unchanged.
Numeric coordinates therefore cannot move hidden zero without moving the
retained source structure.

The marked-seam result does not reject the still-admissible intrinsic-seam or
invariant-equivalence-class alternatives.

## Twist receipt and partial relation

Every one of the fourteen minimum-packet word initiations receives one
`TwistReceipt` linking:

```text
typed Structural Null prestate
  -> exact causal boundary manifestation
  -> marked seam
  -> native positive-frame Möbius root state
  -> exact coordinate (u=0, B=1, t=0)
```

The receipt retains event, source, parentage, law, relation, scope, and version
identity. The word value is not hashed or used to invent a transverse
coordinate. This is why the relation remains honest and partial.

## Motion evidence

`InitiatedCarrierState` keeps local state separate from append-only history.
For two successive one-turn motions:

```text
visible(s + 1) = visible(s)
complete_local(s + 1) != complete_local(s)
complete_local(s + 2) = complete_local(s)
len(history(s + 2)) = 2
```

The changed one-turn distinctions are the native local frame and exact lifted
representative. The second turn restores local state without erasing either
motion receipt. Local return is not construction completion.
